MON CAP — Site web complet

Le dossier contient index.html et tous les fichiers nécessaires dans assets/.

Pour un aperçu local : extrayez le ZIP puis ouvrez index.html dans un navigateur récent.
Pour publier le site : envoyez le contenu extrait (index.html et le dossier assets) vers votre hébergeur en tant que site statique.

Le site est responsive pour téléphone, tablette et ordinateur.
